# 狗头微信助手 · Windows 原生版

版本0.7.0。新增浅色磨砂风原生界面、左侧六页导航、全局人设和每联系人独立人设。沿用现有Tk框架，不是网页界面，不宣称苹果原生材质或实时桌面模糊。监听、窗口关联、后台发送与确认逻辑不重写。

同一已登录微信账号监听多个对象，每人独立关系阶段、目标、背景、历史与审核修改学习。多个独立聊天窗口自动关联，不要求逐个选择工作台。按完整通讯录排除重名；多个微信进程、重名或窗口缺失时停止自动匹配，保留手动设置。

本目录是新增的独立实现，不替换已有 integrations/jev_windows。源码运行/构建需Windows和包含Tk的Python3.14，本机已验证该版本：

```powershell
python -m pip install -r requirements-build.txt
python app.py
./build.ps1 -Python python
```

构建输出在 dist/GoutouWechat.exe。数据默认保存在当前用户LOCALAPPDATA下的GoutouWechatAssistant；不要将运行数据库、聊天、API Key、截图或诊断包提交到仓库。自动发送默认关闭；每人需打开独立聊天窗口，程序每3秒自动匹配，重启后重建关联。窗口标题匹配并非从窗口直接读取微信号，不支持自动打开会话或多登录账号自动匹配。后台发送不得抢前台、占鼠标或剪贴板；未知结果暂停，不盲目重复。
