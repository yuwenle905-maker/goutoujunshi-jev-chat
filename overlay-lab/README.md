# 阿乐悬浮交互模拟器验证

这是独立的验证工程，不是正式悬浮窗IPA，不覆盖阿乐辅助。

实际运行两个iOS模拟器App，使用XCTest真实点击/拖动、现有阿乐辅助LocalOCR、真实系统剪贴板及另一App的UIPasteControl。

验证点：球可拖动/点击收起；透明区触摸穿透到原输入框并可打字；隐藏悬浮层后截取自己的合成聊天画面，运行本地OCR；复制固定的离线测试建议，在另一个App主动粘贴核验。

界限：截图只来自自己的测试App，不是读取微信或其他App；固定建议不是模型生成；普通UIWindow不跨App持续显示，测试也明确核对这一点。模拟器不能证明TrollStore助手进程的全局窗口、系统截图、触摸路由和真实宿主兼容性。实际运行的Simulator版本以evidence/devices.json为准，不冒称iOS17.0真机。

全局方案技术参考：Lessica/TrollSpeed的公开架构说明（独立HUD进程和额外权限），当前实验不使用其私有系统托管实现，也不通过模拟器假装已验证这些权限。
