# 开发与同步计划

更新日期：2026-10-25。目标：同一已登录微信账号监听多段关系，独立记忆、生成回复、逐条确认及可选自动处理。当前0.6.3是后台通道待实机验收版。

## 已实现并有隔离测试

- 多对象读取与独立阶段/目标/背景/状态；历史分页归档、摘要、关系痛点与推进分析。
- 人工审核与自动模式；逐条5秒默认确认，修改停止、关闭取消、过期不发送。
- 本机修改学习、对象隔离、未知发送不重试、人工接管、工作时间和额度。
- 定向窗口后台输入，保留输入全文回读与数据库回执；不回退抢前台或全局输入。
- 通用“输入”标签通过进程与根窗口父链核验；不接受跨窗口或未知标签。
- 脱敏诊断、清空/导出日志；密钥和聊天不上代码仓库。

## 当前待验收，不能标为已完成

1. 文件传输助手：检查唯一输入框与归属通过，再仅发送用户已授权的“后台发送测试”。记录发送前后前台HWND、光标和剪贴板状态以及本机聊天回执；仅检查通过不能代替投递。
2. 后台连续至少三轮、两个测试对象分别收到新消息；窗口被其他应用覆盖时不打断办公，不要求轮流手动选择工作台。
3. 草稿、人工接话、窗口关闭/重建、进程变化、重名对象、失败结果不明：不误发、不重复、状态可解释。
4. 弹窗修改/取消、新来信使旧回复失效、多对象串行；确认后全文一致，学习只保存已确认回执的人工修改。
5. 最小化、隐藏、锁屏不作可用性承诺；只有实测通过的状态才在文档标记支持。

## 每次更新的固定记录

1. CHANGELOG.md记录触发场景、修改、测试和限制；同步本文件状态。
2. 功能变更更新版本；运行源码和最终EXE测试，保留报告并记录SHA256。
3. 源码只同步到指定仓库 integrations/wechat_desktop，不覆盖既有Jev平台目录。
4. Git提交使用中文说明，正常推送；禁止强推。推送后核对远端提交，未成功就明确写待同步。
5. VERSION.json记录本机源码提交、程序哈希、测试数量、真实微信验收状态；不含用户数据。
