# 阿乐辅助 1.0.0

基于本仓库 iOS App 与自有 PC 微信助手关系策略构建的独立 App＋辅助键盘。目标 iOS 17.0 / TrollStore；最低 iOS 16.0。安装包包含主 App、键盘、分享导入和本地截屏扩展，以及原创墨绿对话图标。

## 功能

- 截图本地 OCR、手动核对双方、TXT/CSV/JSON/ZIP 和系统分享导入；不自动读取微信数据库。
- DeepSeek / OpenRouter 回复；原有可选 Jev 策略判断保留。API Key 由用户在设置填写。
- PC 版18张关系策略、23种实际阶段和31种目标；每对象独立人设、表达方式、昵称、撒娇/亲密偏好及避免的表达。应用预设不更改实际阶段，保存后生效。
- 对象加密长期记忆、摘要版本、历史趋势、规则同步；用本人已核对原话及当前对象记忆作风格参考，不是训练模型权重。
- 微信内拼音/英文/小鹤键盘，候选可编辑、复制或填入草稿；发送由用户完成。

## 首次使用

1. 用 TrollStore 安装 IPA，打开“阿乐辅助”。
2. 在设置配置模型和自己的 Key；本地截图识别无需 Key。
3. 系统设置→通用→键盘→键盘→添加新键盘→阿乐辅助；需要联网分析时开启允许完全访问。
4. 在关系页建立对象、选择实际关系与目标，按需应用策略和人设并保存。
5. 导入聊天/截图，核对“我”和“对方”再分析。在微信输入框长按地球切换阿乐辅助键盘，填入候选后检查接收人并发送。

使用独立的 ai.ale.assistant Bundle/App Group/Keychain 标识，可与旧狗头军师并存。不会自动迁移旧App或PC的数据、Key。不要删除旧App来迁移。

## 验证边界

CI执行原有核心/导入/加密记忆/规则/输入/OCR检查、新增18策略与旧档案兼容检查、四target arm64编译、ldid签名及IPA结构权限校验，另运行模拟器离线示例截取浅/深色及大字号。以实际CI结果为准。
真实 iPhone 的 TrollStore 安装、键盘启用、联网模型效果需设备验收；开发过程不使用私人聊天或Key，不发送微信消息。未实现跨App自动监听与自动发送，未添加微信注入Hook。
