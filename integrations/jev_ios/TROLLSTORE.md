# TrollStore 个人构建

2026-10-23：为 iPhone 15 / iOS 17.0 增加独立的 GitHub Actions 真机打包流程。

- 工作流：`.github/workflows/ios-trollstore.yml`，手动运行 **Build TrollStore IPA**。
- 基于现有 Xcode 工程构建 Release / iphoneos / arm64，最低系统版本仍沿用工程的 iOS 16.0。
- 不需要 Apple 开发者账号、证书或描述文件。模型 API Key 安装后在手机填写，不写入构建文件。
- 保留主 App、键盘和实验截屏扩展；原有普通签名及模拟器流程不变。
- 主 App 与扩展使用原有 App Group，主 App 与键盘使用固定的个人构建共享钥匙串组。
- `tools/package_trollstore.py` 使用 Homebrew ldid 伪签名必要权限，不添加解除沙盒或平台权限。
- 打包前检查平台、架构、最低版本、三个 target 的共享组与权限；打包后检查 ZIP 完整性和可执行权限。
- 产物为 `GoutouJunshi-TrollStore.ipa`、SHA-256 和构建信息。Actions 下载的外层 ZIP 需要先解压。

验证状态：本机 Python 语法、工作流 YAML、共享权限一致性及无效输入拒绝检查通过。2026-10-23 云端构建 39928706831（源码 47e7f94）成功，上游源码/工程检查、Release 真机编译、三个 target 的权限检查、IPA 完整性与可执行权限检查全部通过。下载后的 SHA-256 和三个真机 bundle 再次核对通过。仍待 iPhone 实机验证，不能把 IPA 打包成功当作键盘、共享钥匙串及快捷指令已实测。

构建记录：https://github.com/yuwenle905-maker/goutoujunshi-jev-chat/actions/runs/39928706831

不要随意改变 Bundle ID、App Group 或共享钥匙串组，以免更新后无法访问旧配置或 Key。通过 TrollStore 覆盖更新，保留原有数据。

## 0.2.0（2026-10-23）

- 新增对象长期记忆：在关系页进入记忆管理，主动开启后保存对象档案；旧的 `current` 对象首次开启时分配稳定 UUID。默认不把未确认截图写入档案，不自动改变阶段或目标。
- 本轮核对后主动保存，预览连续首尾重叠并选择跳过或保留；不做模糊去重。合并计划带 revision，避免 App/键盘并发写入覆盖；文件锁与原子写入保护旧数据。每对象最多 10000 条，超限明确拒绝，不静默裁剪原文。
- 主 App 和键盘分析均带入当前对象已保存摘要和约 6000 字近期原文。摘要生成是一次显式的回复模型调用，草稿需用户确认；保留摘要版本，删除来源消息会停用当前摘要。更早原文在本机保留，可导出明文 TXT；生成摘要一次仅用旧摘要加最近最多 150 条/18000 字原文。
- 长期档案用 CryptoKit AES-256-GCM 加密，32 字节随机密钥存共享钥匙串、仅本机。文件排除系统备份，原始模型配置解码格式不变。临时键盘会话仍沿用上游 5 分钟和系统文件保护，不宣称全部应用数据均已加密。
- 导入支持 UTF-8/UTF-16 TXT、带 sender/message（可含 timestamp）的 CSV/JSON，以及恰有一份正文的普通 ZIP（stored/deflate，检查 CRC、大小，不落地解压路径）。不猜昵称对应哪一方，不支持微信内部私有聊天卡片、语音解码或直接读微信数据库；每批最多 12000 字。
- 新增 GoutouShare 系统分享扩展，本地接收文本、文件或一张截图（Apple Vision），加密暂存最多 10 批。用户需打开主 App 接收、选择当前对象并核对。生成器、工程成员校验、签名及 IPA 校验均纳入第四个 target。
- 新增离线小鹤双拼音码（非音形辅助码），基于现有授权词库；键盘默认小鹤，通过“中/EN”选择小鹤/全拼/英文并在键盘本机记住。一次仅加载所选拼音索引，控制扩展内存。英文提供大小写和直接输入，未实现系统级英文纠错、词频学习或语音。
- 键盘配色改为系统式灰底/白键/灰功能键，跟随深色模式。核对和分析固定在底部；单条身份按钮有明确反馈，截屏等待页增加三步配置和无需快捷指令的替代路径。
- 联网代码仅允许精确的 DeepSeek、OpenRouter、TypeSafe 模型接口，禁止重定向、缓存及未知服务地址；未发现作者聊天上传服务、广告或统计 SDK。模型服务及 OpenRouter 下游供应商会收到用户主动提交的内容，其留存政策由服务商决定；此结论仅限本次源码和构建，不为其他来源 IPA 或被修改设备作安全保证。
- 最终验证：源码 9672894、构建 39943414040 成功。197 项核心、25 项加密记忆/导入/隐私、40 项离线输入、27 项 OCR 检查及工程成员校验通过；四个 target 的真机 Release 编译、权限回读和 IPA 打包通过。下载后版本 0.2.0 (14)、最低 iOS 16.0、CRC/可执行权限/共享组及 SHA-256 复核通过。SHA-256 为 `3126096586f063eee7c53fc8a8d93a36a0d72c980a217e7ba3a3b8d3163f127d`。未用真实聊天或 API Key 测试；系统分享、触屏布局、iOS 17 快捷指令和小鹤实际输入仍需用户设备验收。
